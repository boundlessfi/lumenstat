## Before you post

- **Security problems** never go on the board. Report them privately as described in the [security policy](/trust/security-policy).
- **Do not post personal data**: no visitor details, no API keys, no ingest keys. If you shared a key by mistake, issue a new one on **Setup** and revoke the old one.
- **Bugs** are easiest to fix with the page you were on, what you expected, what happened, and your tracker version.

## Other ways to reach the team

- **GitHub issues** on [boundlessfi/lumenstat](https://github.com/boundlessfi/lumenstat/issues), if you prefer to work in the open repository.
- **The changelog** in these docs, [Changelog](/project/changelog), lists every change to the live service.

<Note>
  The board runs on UserJot, a third-party service with its own privacy terms. Lumenstat's own privacy promises cover the analytics service, not the board. These docs link to it rather than embedding its widget, so reading the docs loads no third-party feedback script.
</Note>
